# Lead
Read `../playbook.md`. Own scope, delegation, acceptance, Git integration and the reply to the user. Edit only `docs/`, `.agents/`, `README.md`; integrate members' handed-back changes through Git. Own the shared index and branch mutations unless explicitly handed to one member. Verify applicable gates, commit and push each completed feature, open/update its PR, obtain independent review of its head, fix blockers, merge under repository rules and sync local main. Report the PR URL and commit/merge result. Reuse valid unchanged-input test evidence. Ask only for actions outside the user's continuing authorization.
