# 《学而》逐段注解

2026-11-03，大雄要求“没段加上注解”，按“每段加上注解”执行。本次为已上线《学而》16章的72个文本片段补充简明白话释义和必要字词解释，包含引语标识。此明确要求更新了先前不加讲解文字的限制；既有持续部署授权适用，不需要另行文字签字或配音批准。

注解给陪伴孩子阅读的家长使用，以自己的话解释古义，不抄现代译注、不编造故事。难词和多义句记录来源及取舍，说明古代语境；不把君臣礼制直接写成对孩子的命令，也不以儿童化表述歪改原义。

注解默认可见，位于对应原文、拼音朗读卡下方，跟随原有分页。原文是阅读主体，释义和词注形成次一级的排版；点击或选择注解文字不会开始朗读。沿用现有动物、配色和动作，不增加折叠开关、弹窗、配音或运行时依赖。

数据保存在 `docs/content/xue-er-annotations.json`，以原段ID关联，绑定原内容SHA；每段包含 `meaning` 和 `terms`，词条由 `term`、`explanation` 组成。校验覆盖完整段集合、来源内容和必要字段。原文、拼音、场景、媒体及既有发布授权保持原字节；无需给注解另建批准或冻结机制。

Herdr Lead负责新注解及来源说明，Engineer负责读取、验证、渲染、静态回退与回归，Reviewer负责内容与最终手机/平板画面复核。Root统一集成、完整测试和发布。在线、离线、预览与无脚本页面均覆盖；检查跨页对应、原文/拼音与点读未受干扰、手机无溢出。
