# 已知问题与路线图

全书目标与制作方案见 [full-book-plan.md](full-book-plan.md)，首页与停止功能的实现验收见 [homepage-build.md](homepage-build.md)。动漫首页、篇内目录和《学而》16章、26页完整内容已上线，当前源码完整本地回归71/71通过。290份处理后音频通过独立技术核验；负责人随后明确要求“直接全部部署”，本批依 [固定授权](xue-er-release-authorization.md) 发布，真人听检仍待补充。版本和线上结果见 [xue-er-build.md](xue-er-build.md)。

## 已知问题 / 限制
- **未在真机 iPad Safari 上验证**（只做了桌面 Chrome 无头测试）。音频内嵌 + 单一 `<audio>` 的方案是为 iOS 设计的，但需要真机确认首次点击解锁、切后台暂停、静音键下的行为。
- 音频仍内嵌在各章 HTML 中，首页不加载章节音频。更长章节需测量首屏等待与内存，再按页分包或 fetch 为 Blob 播放；离线按章自包含。
- 仓库记录过 Workers 静态资源的 Range/iOS 播放兼容问题；任何新的音频加载方案都需重新实机验证。
- 旧三句流程保留为本地回归用例，线上首章已补齐「子曰」并沿用定稿配音；其他章使用校核后的内容和场景数据。Azure Speech A/B按批准清单完成235次合成，零失败、零自动重试；本批已按负责人直接发布指令上线，后续新素材不继承这次固定范围的例外。
- 图片切层的阈值和多边形是手调的，换图需要重调（见 asset-pipeline.md）。
- 测试只跑 Chromium；没有视觉回归测试；代理无法听音频，音质靠人工听检。
- 没有 404 页面（`not_found_handling: "404-page"` 但未提供 404.html，返回默认 404）。

## 路线图（建议）
1. 真机 iPad / iPhone 测试，并把结果补进测试说明。
2. 继续收集已发布《学而》配音的实际读音、速度和音量反馈，将听检结论绑定到对应文件，按条目定点修正；不重复生成无需修改的定稿。
3. 其余各篇固定底本、制作、校对并分批发布；沿用已验证的分页、互动和按章加载方式。
4. 测试：增加 WebKit 项目、视觉回归（只用插画角色截图），将已有 file:// 测试扩展到更多章节和长章分页。
5. CI：GitHub Actions 跑 `npm test`；可选接入 Cloudflare Workers Builds 自动部署（构建命令 `npm run build`）。
6. 离线/PWA（Service Worker 缓存），适合平板反复使用。
