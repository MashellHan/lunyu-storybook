### B2 · 标点掉到行首或独占行：初次问题记录（集成结论见文末）

复现位置：第15章 P3，320px，第一读句组“《诗》云”之后的冒号落在下一行行首；工程768px截图该组末逗号独占一行。第4章 P1，320px，第二读句组末问号独占一行。新宽景抽查也出现同类问题，说明应在新章的共用文字渲染处处理。

根因是每个汉字/标点都被独立 `.k { display: inline-block }` 切成了可断行单元。请保持现有 `.k`、ruby、`data-segment`、`data-source-index` 不变，在外层合并最小不可断行单元：闭标点（逗号、句号、冒号、问号、后引号等）跟前字，开引号/前书名号跟后字。例如“云：”“‘如”“磨’，”。外层可用 `display:inline-block; white-space:nowrap`。不要删除/替换底本标点、加入可见文字或空格，也不要缩小字号来掩盖问题。

复核只需上述第15章 P3 320/768、第4章 P1 320及一个复用长句：无孤立标点；拼音仍随原字；DOM拼接及来源索引不变。此修正属于新章排版，不要求重跑旧首页视觉专项。
