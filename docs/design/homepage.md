## 1. 已确定的构图

首页是**四动物围坐的绘本入口，旁边是一组连续书页目录**。沿用当前奶油底、木色、深棕文字、圆体中文及柔和动物插画；界面主角是大象老师、小兔、小猫、小狗。首页属于体验入口，目录承担家长选章任务。

- 桌面／平板横屏：左侧「论语」标题与动物围坐，右侧两张相接的目录书页。目录按 01–10、11–20 分页列出，第一篇下面直接展示唯一可读的第一章。
- 手机：标题 → 四动物 → 第一篇及首章入口 → 其余篇目，顺序进入正常文档流。首章入口在 390×844 的首屏内，不必先滑过二十篇。
- 目录用共享纸面、细分隔线和编号建立秩序；每篇不另套浮起的圆角卡片，不做统计区、筛选栏、搜索栏或轮播。
- 动物只在首页承担视觉与一次迎宾动作，不装成可点读按钮。进入首章后沿用既有角色点读。
- 本轮不增加篇内空目录页：只有第一章可读时，从首页的明确章目直接进入第一章。未来有更多真实内容，再在对应篇下增加章目。

## 4. 尺寸与响应式

下表均为 CSS px。页面允许纵向滚动，宽度从 320 起可用；不将整个页面 `transform: scale()`，不锁死 `body` 的高度和滚动。

| 项目 | ≥1024 宽 | 600–1023 宽 | 320–599 宽 |
| --- | --- | --- | --- |
| 内容区 | 最大 1240；左右留 32 | 左右留 24 | 左右留 16 |
| 主构图 | 动物区约 1/3，目录约 2/3；间隔 32 | 动物在上、目录在下；间隔 20 | 单列；间隔 16 |
| 动物区 | 宽 320–400，高约 300–360 | 宽不超过 390，高约 250–280 | 随容器宽度，高约 210–260 |
| 目录 | 两页，每页十篇；页间 24–32 | 两页，每页十篇；页间 24 | 两页上下接续，保持 01–20 顺序 |
| 页内边距 | 16–24 | 16–20 | 12–16 |
| 普通目录行 | 最小高 48 | 最小高 52 | 最小高 56 |
| 标题「论语」 | 56–72，行高 1.15 | 48–56 | 40–44 |
| 篇名 / 章目 | 22 / 22 | 22 / 22 | 20 / 20 |
| 篇编号 | 16–18 | 16–18 | 16 |

书页共用暖白纸面 `#fffaf2`，外缘圆角 20–24，页缝和阴影轻到不抢篇名；每行不单独投影。最长篇名「公冶长」「卫灵公」不截断、不省略。

动物摆位先按一个独立容器排：大象最大、在左后；小兔在右后；小猫与小狗在前排。手机建议大象宽 150–175、小兔 105–120、小猫 95–110、小狗 110–125，窄至 320 时按动物区可用宽度适当收小，仍保持完整形象。主动作周围留至少 12 px 余量；缩小插画不连带缩小篇名和触区。

390×844 验收目标：标题、四只动物、完整第一章链接均在前 600 px 内；二十篇自然向下滚动。320 宽仍不横向滚动。高度小于 500 的横屏将迎宾场景收至约 140–168 高，减装饰留入口，不强行把所有目录塞进一屏。安全区使用 `env(safe-area-inset-*)`；文字放大后允许纸面增高。

## 5. 颜色、触控与键盘

沿用现有系统字体栈，不下载字体。正文深棕 `#4a3424`、次级文字 `#7a5a42`、底色 `#fff6e4`、强调底色 `#f08a5d`。

| 配色 | 已计算对比度 | 用途 |
| --- | --- | --- |
| `#4a3424` / `#fff6e4` | 10.82:1 | 标题、正文 |
| `#7a5a42` / `#fff6e4` | 5.80:1 | 拼音、篇号、未开放篇名 |
| `#7a5a42` / `#fffaf2` | 6.00:1 | 书页次级文字 |
| `#4a3424` / `#f08a5d` | 4.70:1 | 播放图标 |
| `#3b82c4` / `#fff6e4` | 3.78:1 | 焦点轮廓 |

白色三角在现有珊瑚底上约 2.47:1，不用于本次新控件；采用深棕三角。读句的颜色变化保留，但文字本身始终达到 4.5:1；现有浅色未读字和整卡 `opacity: .5` 不作为手机可读方案。当前句同时用静态深色边线／标记指示，不能只靠颜色或跳动。

所有实际控件至少 64×64；相邻控件至少 8 px 净间距。链接用 Enter，按钮支持 Enter／Space；使用原生元素。焦点环 3 px 实线、外偏 4 px，并在复杂背景上加浅色隔离边；不动焦点环、不用 `outline: none`。目录 DOM 顺序与视觉阅读顺序一致，先 01–10 后 11–20。

## 6. 进入、返回与离线约定

| 场景 | 首页 | 首章 | 返回 |
| --- | --- | --- | --- |
| 在线 | `/` | `/learn/xue-er/1/` | `/#xue-er` |
| 离线包 | `dist/index.html`（本稿建议的首页文件名） | 保留 `dist/index-single.html` | `./index.html#xue-er` |

首页「学而」区域设置稳定的 `xue-er` 锚点；返回时恢复该入口的可见位置，键盘导航可恢复到首章链接。不要只用 `history.back()`，直接打开首章也必须能回目录。在线深链直接打开、刷新和资源相对路径均需可用；未知篇章不回落为首章。

离线首页链接 `./index-single.html`；两份 HTML 随包交付，不使用以 `/` 开头的文件链接。每章仍自包含图片、音频与脚本，单独打开首章可读可听；若只单独拷贝首章，阅读不依赖首页，但返回目录需要包内首页文件。离线首页可内联现有角色图，不靠 `fetch` 才出现目录。

首页不创建 Audio、不导入章节的 `AUD`、不内嵌 MP3、也不预加载／预取章节 HTML 或音频。在线仅进入首章后加载该章资源，保留其现有音频兼容方案。进入阅读页展示既有标题与 ▶，声音由阅读页内的实际点击触发；首页进入链接不承担音频解锁。

## 7. 阅读页控制与停止后的呈现

阅读页只保留一排图标控制：左侧返回目录，右侧暂停／继续与停止；不增加文字工具栏。星星沿用真实已完成状态，在有空间时排中间，窄屏可另占一行；不得挤小控制按钮。控制区在标题遮罩、自动朗读、暂停和自由互动中都可见且可点。

| 控件 | 可访问名称 | 行为与画面 |
| --- | --- | --- |
| 房屋／返回图标 | 返回论语目录 | 先取消本页播放及动作，再去实际首页；返回后不继续旧语音 |
| ⏸ / ▶ | 暂停朗读和动画 / 继续朗读和动画 | 冻结／继续同一时间点；图标、可访问名称、`aria-pressed` 与真实状态一致 |
| ■ | 停止朗读，进入自由互动 | 立即停音并取消旧流程，退出标题遮罩，显示全部角色及三句正文，进入 `data-step=free` |

停止需覆盖标题、开场、领读、齐读、独读、庆祝及暂停态。旧等待、延迟动作、动画结束回调不能继续朗读或覆盖自由状态；说话动作、气泡、当前逐字焦点和进度条一并清理。暂停态停止后解除旧暂停，下一次点读能立即使用。

停止不点亮未完成星星，不庆祝，不显示新弹窗文案；已获得的星星保留。按钮保持原位置和键盘焦点，重复停止无副作用；自由点读期间也能停止当前播放。可用一次屏幕阅读器状态提示「已停止，可点角色或句子」，不逐字播报高亮。

停止后角色／句子点击沿用原有领读、跟读、叫声与动画，新点击取消旧点击；从未按过 ▶ 的路径也要能在这次点击中解锁同一个 Audio。页面隐藏自动暂停；回目录、浏览器回退或恢复页面时不能使已取消的自动流程复活。此处定义可见行为，取消机制由 Engineer 接入。

## 8. demo 手机布局的实施建议

将当前固定 1180×820 舞台改为**控制区、角色区、正文区各自排版**，不再通过 `fit()` 整体缩放解决窄屏；删除缩放后留在视口之外的占位关系。保留现有角色、句子、测试 ID 和配音内容。

- 手机正文区宽 `100%`，三句纵向排列；每句原文至少 24 px，建议 26；拼音至少 14 px，建议 15。原文与拼音使用原生 `ruby/rt`，在既有逗号处换行，字音不拆开、标点不丢失。卡片高度自动增长，行距需给拼音及声调留位。
- 每句仍是一整个点读按钮；左右内边距 12–16、上下 14–18，句间距 12，编号缩为约 28–32 的静态标记，不能占用现有 84 px 的大块正文空间。
- 手机角色采用 2×2：大象／小兔在上，小猫／小狗在下；格间距 12，单格约 138–173 宽、148–164 高。图片在格内完整展示，角色按钮覆盖各自格子，热区不重叠。正文在角色区之后，内容超高时页面正常滚动。
- ≥1024 宽可保留四角色横向舞台与三句并排；窄平板优先纵向正文，不能为了三列把拼音缩小。阅读页控制用有实占位的 sticky 区域，避免悬浮遮住第一行拼音；小屏横屏也允许滚动。
- 标题遮罩限定在阅读区域内，手机主标题建议 36–44 px，允许按词组换行；▶ 至少 80×80。返回、暂停、停止层级始终高于遮罩，不被开场动画封住。
- 手机大动作只作用于图片子层，外层按钮位置稳定；纵向位移控制在约 24–32 px，预留动作包络。翻转若会碰到邻近热区或正文，采用已有 `bob/nod/bounce` 的紧凑版本，不改音频与字序。

## 9. 动效与首轮验收

首页只编排一个迎宾焦点：目录和插画从首帧即可见，大象向书页轻轻点头一次（约 640 ms，转角不超过 3°、位移不超过 4 px），其余动物静止陪伴。首章入口立即可用，不等待动画完毕。首页不保留无限呼吸、耳摆、光圈循环，因此无需再加动画工具栏。

| 动作 | 常规 | reduced-motion |
| --- | --- | --- |
| 大象迎宾 | 一次 transform，640 ms | 直接静止展示 |
| 首章链接按下 | 下沉 1–2 px，120 ms | 无位移；即时改变边线状态 |
| 状态显现／退出 | opacity 150–220 ms；退出约为进入的 65% | opacity ≤150 ms 或立即切换 |
| 阅读页动作 | 沿用既有词表；单次点击一个焦点 | 去掉位移、旋转、缩放、眨眼和待机循环，保留静态状态提示 |

只动画 `transform/opacity`；状态色可即时切换。进场沿用 `cubic-bezier(0.16,1,0.3,1)`，退场沿用 `cubic-bezier(0.7,0,0.84,0)`，不用默认 ease。导航不等待退场；隐藏页面取消首页一次性动作，回来不补播。阅读页暂停需冻结全部音频、时间线、CSS／WAAPI 动画；运行中切换 reduced-motion 也应停止位移动画。无 JS 时首页目录与真实首章链接仍可见可用。

工程首版验收清单：

- 二十篇顺序和名称完整；只有学而第一章生成链接，其余篇目没有假链接和无效 Tab 停靠点。
- `/` → `/learn/xue-er/1/` → 返回、深链刷新、离线首页 → 首章 → 返回均工作；首页没有章节音频请求或内嵌音频。
- 查看 1440×900、1024×768、768×1024、390×844、320×568 和 844×390：首章入口易找，手机无横向溢出，角色、原文、拼音、控件可见可读可点。
- 每个自动阶段及暂停态都能停止；停止后无旧回调、无假星星，角色和句子立即可用，快速连点不叠音；后台暂停有效。
