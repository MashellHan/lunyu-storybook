## 内容边界与实施方式

- 生产文字、逐字拼音、读音例外以 Content 的 [xue-er.json](../content/xue-er.json) 为唯一入口，校核状态见 [内容交接](../content/xue-er-review.md)。设计不另造一套拼音或覆盖底本标点。本文编制时该稿先交了1–3章，4–16章的场景／分页按同一固定底本规划；后续内容状态以该稿为准。
- 章号固定为 `xue-er-01` 至 `xue-er-16`。下文中文场景名仅供制作辨认，**不加到页面或配音里**。页面仍只有允许的标题、章目、原文／拼音、既有重读句及叫声；控制用图标与可访问名称。
- 动物是朗读伙伴，不把兔、猫、狗标成孔子、曾子或子贡。`speaker` 保留原文人物；画面主答角色是另一字段。引语标识全部显示、朗读，不因分镜删除“子曰”“有子曰”等文字。
- 复用七个现有 WebP 图层：大象一层、小兔耳／身、小猫一层、小狗尾／身／头。不改图、不增加身体姿态或手臂层；场景用 CSS／内联 SVG 的门、树、书、桌、圆片等简单形状。道具放在独立台面或地面上，不硬塞进原图的爪子里。
- 每章至少改变两项：空间结构／角色主次与站位／核心道具／动作机制。共享手机排法不等于复用同一场景：各章仍有不同的地面结构、道具与动作目标。不存在“换底色就完成下一章”的方案。
- 工程只需少量场景类、道具模板和按章动作配置；不需要框架、通用场景编辑器、实时骨骼系统或新增服务。

## 共用尺寸与交互

以下尺寸供新章使用，第1章在首页阶段保持冻结；正式补齐首章时另按内容阶段接入。

| 对象 | 桌面／平板 | 320／390手机 |
| --- | --- | --- |
| 场景区 | 1024以上先以约 920×320 的独立局部舞台布置；宽度随容器收缩；768采用窄屏排法 | 可用宽度约288／358；常规场景高224／252，最多260／280；不足时让正文自然向下滚动 |
| 角色 | 大象完整图片约156–180宽，孩子112–144；主次由大小与位置区分 | 2×2时图盒约104／124；1+3时老师120／140，孩子80／96。角色按钮至少80×80，脸与耳尾完整；不能把整页缩小 |
| 原文／拼音 | 正文26–30、拼音至少14；随原文字逐字对应 | 正文至少24、拼音至少14，行间给 ruby 留足空间；卡片内边距16，字不压在道具上 |
| 控件 | 沿用返回／暂停／停止的深棕图标和64×64热区；仅长章增加翻页 | 页尾两个48×48箭头，间距至少12；提供“上一页／下一页”及目标页的可访问名称，无手势专属操作 |
| 道具触区 | 可交互道具至少48×48，与角色／文字触区间隔8以上 | 小图形外包48或56的透明按钮；单页最多一个主要道具交互区，只有三省场景允许三格分别点读 |
| 空间与颜色 | 奶油底、深棕文字、既有珊瑚／木色；背景低对比，道具不充当状态文字 | 角色与正文分区，场景结束后保持连续底色；重要图标对比至少3:1，正文至少4.5:1，保留蓝色焦点环 |

舞台与正文是相邻的正常布局块。地面、树根、桌脚都绑定**场景局部**；影子绑定每只动物的可见脚底，不能把整章容器的百分比高度当成地板位置。旧轮已关闭的手机坐垫光环／悬空地毯问题不得在长章复现。

仅保留五种容易实施的角色排法，并在各章组合不同道具：

| 排法 | 桌面结构 | 手机对应 |
| --- | --- | --- |
| 弧座 | 老师偏后，三个孩子形成开口弧，前景留给道具 | 1+3；老师居上，三个孩子横排，孩子图盒不能小于80 |
| 双组 | 两个前后错开的二人组，中间留一条门／树／桥的空间 | 2×2；中间装饰条宽24–40，不穿过角色按钮 |
| 对话 | 主问、主答左右相对；两位陪读在后方，保持轮廓分开 | 两主角在前排，两陪读在后排；移动焦点道具，不移动整排人物 |
| 横案 | 前景低桌形成横向轴线；老师与孩子在其后和两端 | 老师上方、孩子下方；桌面缩成中间或侧边的局部道具，不横切脸／腹部 |
| 环座 | 四角围绕一个小中心道具；中心留空 | 2×2；中心道具直径56–72，动物可见轮廓距它至少8 |

读句、角色点击与道具点击使用同一份音频／时间轴引用。点道具等于点其关联的原文句，不能凭空播放解释。正文卡依然是完整、稳定的主入口；道具不是解锁下一句的小游戏。

## 16章分镜

### 01 · 学而时习之：已有书房围坐

- **空间／分工：**保留现有四动物、书房、三句卡与兔→猫→狗独读分工。大象领读，三个孩子正式齐读；各自的叫声和既有动作保留。
- **差异／互动：**它是整篇的熟悉起点，保留点角色、点句子、停止后自由互动。此章不叠加后续章节的新道具或新背景。
- **接入界限：**首页发布期间三个首章源文件冻结。整篇阶段把 `xue-er-01-s01` 的“子曰：“与第一句连续显示／朗读；正文三句及既有 v5 不重录。引语标识不单独占一页，也不伪造其音频已存在。

### 02 · 其为人也孝弟：院门与根系

- **空间／分工：**双组布局；矮树放在中间后方，树根仅在树下的窄土层内可见。大象与小兔靠门，小猫、小狗在外侧；主答为小兔。两页由院门关系转向根系，不换角色原图。
- **道具／动作：**一棵圆冠树、一扇半开门、一片根系 SVG。第2页点树下48×48区域，对应“君子务本，本立而道生。”；根系整体由底部 `scaleY(.9) → 1` 与 opacity 变化，420 ms一次。随后小兔轻点头，二者依次执行。
- **手机：**2×2，树干与根系缩在中间24–32宽的空隙／底部24高土带；根不能伸入文字。第1页门是静态背景；不画打斗、服从评分或虚构对白。

### 03 · 巧言令色：素纸屏风

- **空间／分工：**对话布局；小兔与小猫在屏风两侧，大象、小狗在后方。小猫主答；背景由两扇短屏风形成竖向构图，与书房／树院不同。
- **道具／动作：**屏风前有一页素纸和可收拢的小纸扇。点纸扇重读整句；扇的两片代码图形各转回约6°，420 ms一次，露出同一张素纸。角色只轻点头，不做夸张假笑／变脸。
- **手机：**两个主角保留较大脸部，纸扇位于中间56热区。画面不把美丑、颜色或面部特征当作仁德判断，也没有新增对错标签。

### 04 · 吾日三省吾身：三格书案

- **空间／分工：**横案布局，一张矮书案分成三个明确格位；小狗居中，大象在后，猫／兔分两侧。小狗主答三问，其他孩子仍参与正式跟读。
- **道具／动作：**三枚小木片分别绑定“为人谋而不忠乎”“与朋友交而不信乎”“传不习乎”。点一格，仅该木片抬起3px再落下，480 ms；不同时点亮三个格子。完成星星仍来自真实读完的内容，不能点木片就加进度。
- **手机：**三格各56×48、间距8，放在两排角色之间或场景下缘；两页切换只改变当前问句焦点，不搬动桌子。屏幕不加“三省”解释或问题选项。

### 05 · 道千乘之国：田埂与小车

- **空间／分工：**双组改成沿斜田埂错开的队列；大象在高处，小狗与小兔在田边，小猫在小车旁主答。两条田垄形成纵深，移除室内桌墙。
- **道具／动作：**无武器的简化木轮小车、两块田地和一片静态季节叶。点车对应“敬事而信，节用而爱人”；车整体向前6px并返回、轮子转约20°，600 ms一次；角色和叶子保持静止。
- **手机：**田埂只作场景内部斜带，小车缩为56×48，放在侧边空隙，不能成为第五个拥挤的大角色。古代制度不靠车辆造型冒充考据，页面无说明文。

### 06 · 弟子入则孝：门内门外与书角

- **空间／分工：**双组被一扇门区分内／外；小狗在门外主答，小兔、大象在门内，小猫在低书架旁。第1页是门的关系，第2页书角成为视觉中心。
- **道具／动作：**门扇、两本无字的书。第1页点门对应“弟子入则孝，出则弟”，门扇只平移6px收拢，420 ms；第2页点书对应“行有余力，则以学文”，书页以小角度翻开一次。每页只有一个主要动作。
- **手机：**保留2×2；门框只在中间空隙，顶部横梁在角色头顶外。书页放在场景侧下方，不挤压拼音。不要求拖动物穿门。

### 07 · 贤贤易色：长凳上的书卷交接

- **空间／分工：**横案的桌改成长凳与独立小书架，视觉轴由左向右。三页主答依次是小兔、小狗、小猫；大象固定在后方，引导角色次序变化而非不断换背景。
- **道具／动作：**一卷没有附加文字的书卷放在独立托盘上。点书卷重读当前页最后一个完整短句；书卷朝本页主答者方向移动8px后停回，520 ms。不做手臂递接，不演出原文之外的具体故事。
- **手机：**1+3；主答者仍在自己的固定座位，采用托盘位置和一次点头引导注意。三页不突然交换动物位置，避免键盘目标跳动。

### 08 · 君子不重则不威：积木修补台

- **空间／分工：**环座；中心是一座不超过三层的方块台，视觉重点是稳定的竖向结构。小狗靠前主答，大象在后，小猫与小兔分左右。
- **道具／动作：**顶层一块木片初始偏移4px；点它重读“过，则勿惮改”，该片滑回对齐，360 ms一次。再次点击从静态微偏位置重演，旧动画先取消；不让整座塔坍塌。
- **手机：**中央56×56，四角色都在外侧。没有按能力高低排列伙伴，没有把“无友不如己者”做成排斥某只动物的交互。

### 09 · 慎终追远：老树与静灯

- **空间／分工：**弧座，四角色围在低矮树基旁；树冠形成上方遮荫，侧边一盏小灯。大象领读，小兔主答；这是安静、留白较多的一页。
- **道具／动作：**点灯重读整句，只让灯边一片落叶下移4px并落定，400 ms；灯保持稳定，不闪烁。完成后不安排烟花、翻跟头或追逐叶子的庆祝。
- **手机：**1+3，树冠不罩住脸，灯热区48×48且不贴正文。用克制的物件表达追念，不新增人物照片、墓碑剧情或惊吓画面。

### 10 · 夫子至于是邦也：廊下问答

- **空间／分工：**对话布局，两个立柱与短檐框出廊下空间。小兔在左侧主问、小猫在右侧主答，大象与小狗分后排。角色分工是领读表演分工，不改原文的“子禽／子贡”署名。
- **道具／动作：**低桌上一个书签作轮次焦点。第1页点左侧主角色重读提问；第2页点右侧主角色重读答句。翻页时书签在静态左右两个位置切换，220 ms opacity，不飞过文字；每次只一位角色轻点头。
- **手机：**双主角在前、陪读在后，两页保持同一站位。问题和回答完整跨两页，禁止删掉“子禽问于子贡曰”“子贡曰”。不用另加问号气泡或对白标签。

### 11 · 父在观其志：窗前旧书

- **空间／分工：**横案，中央低书架在一扇长窗下；小猫靠书架主答，大象居左，兔／狗在右侧。窗框与平放的书形成横向安静构图。
- **道具／动作：**同一本书的三张无字书页从前到后叠放。点最前一页重读“三年无改于父之道，可谓孝矣”；只让一角抬起4°再落回，500 ms。不播放计时器、不把三年画成解锁等待。
- **手机：**1+3，窗退至背景，书架仅保留中间56宽的局部。不要用现有动物冒充逝去的父亲，也不新增丧葬剧情。

### 12 · 礼之用和为贵：有边界的圆桌

- **空间／分工：**环座；中间是一张带一处缺口的圆桌／圆形拼片，四角色围着中央留白。小狗主答第1页，小兔主答第2页，大象始终领读。
- **道具／动作：**点缺口对应本页句子：第1页“礼之用，和为贵”，拼片从缺口边6px处合入；第2页“不以礼节之，亦不可行也”，同一拼片到边缘就停回，不越过桌边。全程420 ms，只动该片。
- **手机：**中心直径64，外圈角色轮廓至少相隔8。拼片位置预先定义，点击即可，无拖拽精度考验、计分或错误提示。

### 13 · 信近于义：三段小桥

- **空间／分工：**双组，左右各两位角色，一座很低的三段小桥连接两侧；下方只是窄浅沟，无流动水特效。大象／小猫在一侧，兔／狗在另一侧，小猫主答。
- **道具／动作：**桥面三段分别关联三句，但只用桥中央一个56热区：顺序点读当前选中的句子时，对应一段从低2px的位置轻轻落定，350 ms；句子卡可直接选任意句。初始桥一直完整可见，不把未读显示成危险断桥。
- **手机：**2×2，桥作为两组之间的56–72宽小连接，不横穿动物脚或按钮。三段有木纹线区分，不靠颜色独自区分。

### 14 · 君子食无求饱：林边书亭

- **空间／分工：**偏置横案；一侧是简洁斜顶书亭，另一侧是开放空地，大象在亭下，小兔带读句焦点居外侧，猫／狗在低书箱两端。
- **道具／动作：**一本打开的无字书、一条书签、简单木箱。点书签重读“敏于事而慎于言，就有道而正焉”，书签朝大象所在方向移动8px再停回，500 ms，随后小兔轻点头。
- **手机：**1+3；亭只占背景一侧，屋顶不能压角色头部，书箱缩至56热区。不把少吃或简陋居所做成儿童任务，也不新增生活教导文案。

### 15 · 贫而无谄：打磨书案与四轮对话

- **空间／分工：**对话＋低工作台；小猫在左主问，大象在右领读，兔／狗在后作正式跟读伙伴。四页分别对应原文四轮发言，主次左右轮换，角色不整排移动。
- **道具／动作：**圆钝小磨块、带切面的木片、平整木片与一本素书。第3页点磨块对应“如切如磋，如琢如磨”：磨块移动5px并转6°，接着两种木片以opacity切换，合计650 ms；不动画修改路径、不出现锋利工具。其余页仅书签切换焦点，不能四页都上打磨循环。
- **手机：**主问／主答在前，两陪读在后；工作台保留56×56核心道具。第3页较长的《诗》引文可自然换行，但不另截掉引语、改成摘要或挤小拼音。

### 16 · 不患人之不己知：并肩看书

- **空间／分工：**弧座改成两个并肩的阅读席，前景两本朝向伙伴的书；大象靠后，小狗主答，小兔与小猫并肩。背景留出一侧开放视野，与上一章正面对谈形成区别。

## 动作、停止与无障碍契约

- 每次只有一个主要焦点：道具动作结束再点头；正式齐读时三人使用同一预混音，但不安排三种大动作同时表演。短章不硬凑三句／三颗已完成星。
- 新场景动作只用transform／opacity，通常350–650 ms，最多一次；反馈120 ms。复用现有EASE_OUT，不动width、height、left、top、滤镜或SVG路径。小狗可复用现有头／尾／眼皮层；猫／象不凭空拥有可独立眨动的眼睛层。
- 不添加背景风、云、树叶、灯光的连续循环。静态场景默认已经完整可见，JS失败也不把正文藏掉。动画的结束不是配音播放完成的替代条件。
- reduced-motion保留同样的文字、道具、可点区域和音频流程；去掉旋转／位移／缩放，只允许短opacity状态变化或直接置最终状态。
- 每次点击复用现有统一取消与单Audio机制；再次点击、■、翻页、返回目录使旧回调失效，取消WAAPI和待执行动作。⏸冻结媒体与动作；后台自动暂停。停止不补星、不改写真实完成状态，立刻可重新点读。
- 角色按钮、道具按钮和原文卡均可用Tab、Enter／Space；焦点环清晰且不裁切、不动画。装饰树、墙、桌脚、影子为 `aria-hidden`，不挤进键盘顺序。道具按钮名称说明“重读”及其原文，不增加可见标签。
- 正文不得落到场景绝对定位层；200%文字放大时允许变长／纵向滚动，控制始终可达，不出现将整页缩至微小字体的回退。

### 字段如何接入

| 字段 | 工程读取规则 |
| --- | --- |
| `chapters[].chapterId`／`sceneId` | 前者对应稳定原典章号，后者仅为内部场景标识，不显示为新标题。首章使用 `legacy-demo` 保留既有布局／动作。 |
| `pages[].segmentIds`／`sourceRange` | 原顺序连续内容；从Content直接读取文本与拼音。`sourceRange` 是全章Unicode码点半开区间，不是JS字符串的UTF-16码元索引；需要按范围取文时使用 `Array.from(fullText)`。 |
| `readingGroups` | 明确的朗读组与音频句引用：先由大象按组内segment顺序领读，再由孩子预混音按相同顺序跟读。每组的 `responder` 决定主答／独读角色，不改Content的原文人物 `speaker`。 |
| `audioContract` | 用 `(segmentId, role/ensemble)` 查工程媒体清单；引语片段与后文连续播放，不重录首章已定稿。新声音缺口不妨碍配置交接，但不能把未完成章标为ready。 |
| `layoutPresetId`／`characterSlots` | 五种几何排法；所有现有角色图层按原叠放顺序复用。宽度不足只换场景排法，正文和按钮不跟着缩放。 |
| `props`／`propTemplates` | 已给定SVG viewBox、简单几何节点、色值、部件ID、层级和位置；没有SVG文字、外部图片或新媒体。无需额外绘图工具或通用场景引擎。 |
| `propBindings` | 只为当前页列出的道具生成一个真实button。未绑定的道具、其他页的木片都是装饰，不占Tab、无音频操作。可访问名称来自该朗读组原文。 |
| `onReadCompleteCueId`／`cues` | 有效播放完成后才执行；step依次执行，同一step只动同一道具的部件或同一角色，不能同时动不同焦点。静态定位与WAAPI内层分开。 |
| `motionPresets`／`motionContract` | 已给关键帧、时间、枢轴、次数和reduced-motion分支。停止／翻页／返回／新点击统一取消；暂停和后台冻结。切换reduced-motion只取消场景动作、保留读音流程，不误停音频。 |

几何统一使用CSS px：`x = sceneWidth × cx + dxPx − widthPx / 2`，y取 `topPx`。场景宽为视口减两侧留白后再取max-width，**不是缩放整幅固定画布**。道具居于 `propDock` 中心，再加自己的dx／dy；完整矩形就是点击区，不能把透明外框裁到小图形轮廓。手机阶段：320–389视口使用高260的compact场景；390起使用高280的phone场景。正文在场景之后自然排版，角色／道具动作不改变其高度。
