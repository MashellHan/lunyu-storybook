## 重点取义

| 位置 | 本稿取义 |
| --- | --- |
| 1.4 三省 | 依朱注“以此三者日省其身”，释为检查下文三件事；不规定一天只能或必须恰好检查三次。 |
| 1.4 传不习乎 | 依“传，谓受之于师”，指老师传授给自己的内容有没有温习掌握，不倒解成自己教别人之前是否练过。忠在本章取尽心，不作忠君。 |
| 1.7 贤贤易色 | 依朱注，前贤为敬重，后贤指贤德者；易色取把好美色之心转向好贤德。对读快照另载“改易颜色”的解释，本稿不采用。 |
| 1.8 无友不如己；学则不固 | 依朱注“友所以辅仁”的进德语境，保留不以德行逊于自己者为友的原有择友标准，不改成按成绩、贫富挑人，也不译成“没有人不如自己”。固取所学牢固，不取固执。 |
| 1.11 父之道 | 观其志、观其行考察的是儿子。三年保留古代丧礼语境；父之道指父亲留下的行事原则、办法，结合朱注所引尹氏“如其非道，何待三年”，不解释为错误做法也必须照办。 |
| 1.13 因不失其亲 | 依朱注“因，犹依也；宗，犹主也”，指依靠值得亲近的人，并可尊之为依托；亲不专指亲戚，因不作因果连词。前两句的信是约信，复是践言。 |
| 1.15 往／来 | 依朱注，往是已经说出的，来是尚未说出的；指由已讲之理推知未讲之意，不译成预测未来。《诗》引句用切磋琢磨说明已有进步还可继续精进。 |
| 1.10 人物与俭 | 子禽记为陈亢，不在朱注所载两种师承说法之间强作结论。子贡为端木赐。俭取节制自己，不只解释成省钱。 |

君臣、犯上、征役、丧祭与礼制按古代语境转述，不把这些关系变成现代孩子必须服从的命令，也不抹去原书所谈的关系。1.7致其身保留委身、甚至献身之意并标明时代语境；1.14不求安饱指志向不在口腹安逸，不要求孩子挨饿。学习德行与学文相互联系，1.7“虽曰未学”不扩写成无需读书。
