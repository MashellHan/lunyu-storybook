# 统一风格前缀
为面向3岁幼儿的互动绘本网站设计原创小动物角色。

温暖、可爱、精致的二维儿童绘本插画，圆润饱满的轮廓，大头小身体，柔软的小短手和小短腿。使用奶油色系和低饱和暖色，带少量柔和的体积阴影，线条干净、圆滑、粗细统一。画面简洁，角色轮廓清楚，缩小到平板屏幕上仍然容易辨认。

表情自然、有亲近感，眼睛明亮但不过分巨大，避免僵硬的微笑。角色像可以陪孩子一起读书的温柔伙伴，不像严肃的教师或商业吉祥物。

单个角色，全身完整，正面略微转向画面中心，平视视角，自然坐姿，身体和四肢关系清楚。角色居中，四周留出充足空白，不裁切耳朵、头顶、尾巴和脚。

# 大象爷爷
角色：一位慈祥、精神饱满的大象爷爷，是小动物们的读书伙伴。

浅灰蓝色皮肤，圆圆的头，宽大柔软的耳朵，额头有少量温和的皱纹，眉毛稍浅，戴细圆框眼镜，眼镜不能遮住眼睛。围一条简洁的暖杏色小围巾，不穿复杂衣服。

身体圆润稳重，比小动物更宽大，但不显笨重。鼻子自然弯向身体一侧，不遮住眼睛和嘴部表情。省略明显的象牙，不使用长胡须。

自然坐着，一只前脚轻轻抬起，像在温柔地邀请大家一起读书。嘴角带着放松的笑意，既有爷爷的可靠感，也有一点俏皮和童趣。不要训话或指责的姿态。

保持眼睛、嘴巴、耳朵与围巾轮廓清楚，便于后续制作眨眼、说话、摆耳朵和点头动画。

# 通用限制
纯净的单色背景，无场景、无文字、无汉字、无字母、无水印、无标志、无边框、无其他角色。

不要写实动物，不要照片质感，不要复杂毛发，不要恐怖或诡异表情，不要尖牙，不要夸张肌肉，不要巨大玻璃眼睛，不要过度高光，不要荧光色，不要复杂服装和装饰。

不要多余肢体、重复耳朵、错误爪子、融合的手脚或断开的尾巴。不要让道具遮住脸部和身体。不要模仿已有知名动画角色。

背景：如支持透明背景就用透明，否则纯白背景。
